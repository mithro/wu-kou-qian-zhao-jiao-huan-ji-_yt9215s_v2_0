# Gerber and drill files

Fabrication files for pankanwen's
[YT9215S 5-port gigabit switch](https://oshwhub.com/pankanwen/wu-kou-qian-zhao-jiao-huan-ji-_yt9215s_v2_0)
(board `Board1`, PCB `PCB1`). Licence and credit as in the [top-level README](../README.md)
(CC BY-NC-SA 3.0, by pankanwen).

To order boards, upload **[`Gerber_PCB1_2026-11-03.zip`](Gerber_PCB1_2026-11-03.zip)** to the
fab as it is. The other files in this directory are the same files extracted from that zip,
unchanged, so they can be viewed and diffed on GitHub.

## Files

| File | Contents |
| --- | --- |
| `Gerber_TopLayer.GTL` | Top copper |
| `Gerber_BottomLayer.GBL` | Bottom copper |
| `Gerber_TopSilkscreenLayer.GTO` | Top silkscreen |
| `Gerber_BottomSilkscreenLayer.GBO` | Bottom silkscreen |
| `Gerber_TopSolderMaskLayer.GTS` | Top solder mask |
| `Gerber_BottomSolderMaskLayer.GBS` | Bottom solder mask |
| `Gerber_TopPasteMaskLayer.GTP` | Top paste (stencil) |
| `Gerber_BottomPasteMaskLayer.GBP` | Bottom paste (stencil) |
| `Gerber_BoardOutlineLayer.GKO` | Board outline (100 × 65 mm, 3 mm corner radii) |
| `Gerber_DocumentLayer.GDL` | EasyEDA document layer (not manufactured) |
| `Gerber_DrillDrawingLayer.GDD` | Drill drawing (not manufactured) |
| `Drill_PTH_Through.DRL` | Excellon drill, all plated holes and slots (pads and vias) |
| `Drill_PTH_Through_Via.DRL` | Excellon drill, plated via holes only (a subset of the file above) |
| `Drill_NPTH_Through.DRL` | Excellon drill, non-plated holes (mounting holes and RJ45 locating pegs) |
| `FlyingProbeTesting.json` | Flying-probe test data generated by EasyEDA: component positions and every pin with its net, pad shape/size and hole (units: mil) |

The zip also contains EasyEDA's `How-to-order-PCB.txt` (a link to
<https://prodocs.lceda.cn/cn/pcb/order-order-pcb/index.html>). It was left out of the
extracted copy.

Gerber units are millimetres (format 4.5, absolute). Excellon files are metric.

## Provenance

* Exported on 2026-11-03 from the original public project
  (`81622a3a90204e8685b9f33b56559349`) in the JLCEDA Pro web editor, **V4.1.93**.
* *Export → PCB Fabrication File (Gerber)*, **One Key Export**, default settings,
  colourful silkscreen off.
* The design was not edited. The DRC prompt was answered "No, Continue Exporting", so
  no DRC was run as part of the export.
* `Gerber_PCB1_2026-11-03.zip` sha256:
  `002700ac6c480e9133d29f237347878efe600f5ec2399cb6ee3f17a87881507a` (368,260 bytes).

The export was run twice. The two zips have different hashes, but they make the same board.
Apart from the timestamp in each file header, the only difference is one aperture per
Gerber layer that is defined but never used. EasyEDA gives it a different size on every
export, and the apertures after it are renumbered. With aperture numbers resolved to
their shapes, every layer's drawing commands are identical, and the drill files differ
only in the timestamp. So expect a fresh export of this design to differ from these
files in the same way.

## Checks against the design

Compared with [`../pcb/pcb-info.txt`](../pcb/pcb-info.txt):

| `pcb-info.txt` | These files |
| --- | --- |
| Board 3937 × 2559.1 mil | Outline extents 100.000 × 65.000 mm |
| 2 copper layers | `GTL` + `GBL` |
| 345 vias, all through | `Drill_PTH_Through_Via.DRL`: 190 × 0.3048 mm + 155 × 0.305 mm = 345 |
| 89 plated through-hole pads | `Drill_PTH_Through.DRL`: 427 holes − 345 vias = 82 holes, plus 7 slots = 89 |
| 0 non-plated pad holes, 14 cut-out regions | `Drill_NPTH_Through.DRL`: 14 holes, 4 × 3.2 mm mounting holes + 10 × 3.25 mm RJ45 locating pegs |

The design's 14 cut-out regions are exported as non-plated drill holes, not as routing on
the outline layer. Top and bottom copper were rendered with `gerbv` and match
[`../pcb/pcb-editor-view.png`](../pcb/pcb-editor-view.png).
